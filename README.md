# Blinkit Grocery Sales Dashboard

A Power BI project focused on analyzing Blinkit grocery sales data and presenting key sales insights through an interactive dashboard.

## Dashboard Preview

![Blinkit Dashboard](Blinkit-Dashboard.png)

## Key Analysis

- Total sales and average sales
- Average product ratings
- Number of items sold
- Sales by item category
- Outlet-wise sales performance
- Sales based on outlet size and location
- Low-fat and regular-fat product comparison

## Tools & Technologies

- Power BI
- Power Query
- DAX

## Project Overview

This project helped me explore sales data, create visualizations, and build an interactive dashboard to understand sales trends and outlet performance.
